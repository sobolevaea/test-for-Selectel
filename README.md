# Проект: "Меню"

Frontend-проект, демонстрирующий работу с React, TypeScript и клиентским роутингом.

## ▷ [Live-версия](https://sobolevaea.github.io/test-for-Selectel/)

## О проекте

Проект реализует меню с разделами и возможностью выбора элементов.  

Пользователь может:
- переключаться между разделами меню;
- выбирать элементы через чекбоксы;
- видеть количество выбранных пунктов и общую стоимость;
- использовать клиентский роутинг для навигации.

Основная цель — показать работу с компонентной архитектурой, состоянием и типизацией.

## Технологии

- React
- TypeScript
- React Router
- HTML, CSS 
- Функциональные компоненты и хуки

## Запуск проекта

Установите зависимости:
```bash
npm ci
```

Запустите проект в режиме разработки:
```bash
make run
```
Приложение будет доступно по адресу: http://localhost:5173

## Сборка

Для сборки production-версии:
```bash
make deploy
```
